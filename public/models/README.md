# MediaPipe model asset

`hand_landmarker.task` is the official MediaPipe Hand Landmarker (full, float16) model bundle distributed by Google.

Source: <https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/latest/hand_landmarker.task>

The model is used locally by the browser; webcam frames and landmarks are not uploaded.
